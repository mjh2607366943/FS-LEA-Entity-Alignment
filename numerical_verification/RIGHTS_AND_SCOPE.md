# Rights and scope

A: Author-written numerical checking code, documentation, configuration records and anonymous numerical derivatives are local sharing candidates; explicit author/institution redistribution approval and licence are not established merely by this classification.
B: Actual graph profiles, instantiated prompts/responses, standardized data, author-provided ZH-EN embeddings and legacy source excerpts require source/permission checks; none are included.
C: Jina weights and third-party model/code resources must be acquired from their official sources under applicable terms; no weight or upstream implementation is redistributed here.
Excluded: credentials, private identity map, raw API logs, payment/account information, private data, model checkpoints and full score matrices.

This directory is not an end-to-end reproduction bundle or an anonymized manuscript submission. The numerical Q/T records are pseudonymized; no map back to original entities is provided. This is a faithful format derivative, not a new experiment.
