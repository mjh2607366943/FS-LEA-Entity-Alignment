The payload contains author-project numerical checkers, configurations, documentation and pseudonymized saved-result derivatives. These files are candidates for approval, not certified unrestricted assets. Approval should cover the derived numerical data as well as code and documentation.

Readers must not interpret visibility on GitHub as permission to redistribute excluded resources or as an end-to-end reproducibility claim. Distribution terms should be added only after a rights holder chooses and approves them; an absent LICENSE is not an open-source licence.
